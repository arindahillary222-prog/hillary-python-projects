# Contributing

Work only inside `engineering-ai-platform` unless a change is explicitly authorized. Run `python3 -m pytest -q` and `node --check frontend/app.js` before committing frontend or backend changes. Keep engineering claims proportional to the evidence and add provenance, assumptions, limitations and benchmark coverage for new numerical methods.

Do not commit secrets, private customer files, personal documents or unapproved manufacturing records. Do not introduce arbitrary code execution without isolation limits. Keep the route manifest synchronized with page routing and use clear status labels for available, screening, foundation and roadmap capabilities.
