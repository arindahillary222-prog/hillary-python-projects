# Technologies and dependency register

- FastAPI and Pydantic: typed HTTP API and input validation; permissive MIT/BSD ecosystem.
- Python standard library: deterministic engineering formulas and timestamps.
- Three.js and OrbitControls: browser WebGL geometry and camera interaction; MIT license.
- IBM Plex Mono / Inter via Google Fonts: interface typography.
- Cloudflare Pages and Pages Functions deployment context: public frontend hosting.

Candidate technologies for later validated integrations include IfcOpenShell/buildingSMART-compatible tooling, vtk.js, EPANET, SWMM, Monaco Editor, JupyterLab, Pyodide, Apache ECharts, pvlib and selected numerical engines. Each candidate requires a maintenance, security, runtime and commercial-license review before production use. xeokit AGPL/commercial licensing must be resolved before any proprietary SaaS use.
